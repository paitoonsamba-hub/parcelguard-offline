# ParcelGuard Offline Android 0.2 Beta — คู่มือภาษาไทย

## จุดประสงค์
ใช้มือถือ Android ติดตั้งเหนือโต๊ะแพ็คสินค้า อ่าน Barcode/QR บนใบปะหน้าโดยอัตโนมัติ ถ่ายภาพหลักฐานที่มี Tracking/รหัสถุง/วันเวลา และเก็บข้อมูลในมือถือแม้ไม่ใช้อินเทอร์เน็ต

**นี่คือซอร์สโค้ดทดลอง ไม่ใช่ APK ที่ยืนยันว่าทดสอบกับ Vivo V29 หรือ Samsung แล้ว** ต้อง Build ผ่าน GitHub Actions และทดสอบในเครื่องจริงก่อนใช้งานกับพัสดุของลูกค้า

## ฟังก์ชันที่มีในโค้ดรุ่นนี้

- CameraX + ML Kit แบบ Bundled อ่าน Code 128, Code 39, EAN-13, ITF และ QR (กล้องหลัง)
- สแกนซ้ำ 2 เฟรมเพื่อยืนยัน จากนั้นบันทึก JPEG อัตโนมัติ และรอให้ยกพัสดุออกจากกล้องก่อนรับชิ้นถัดไป
- ข้อความกำกับในรูป JPEG: Tracking, รหัสถุง, เวลา; และ Tracking บนจอขณะสแกน
- เสียงบี๊บเมื่อบันทึกสำเร็จ และเสียงเตือนเลขซ้ำ
- เปิดถุงใหม่, ปิดถุง, ตั้งจำนวนพัสดุเป้าหมาย, แจ้งเมื่อจำนวนไม่ตรง
- ใช้ฐานข้อมูล SQLite ในเครื่อง; เมื่อปิดแล้วเปิดแอปใหม่จะกลับไปถุงที่ยังเปิดล่าสุด
- ค้นหารายการ Tracking ด้วยข้อความบางส่วนหรือรหัสถุง; กรองจากวันที่/ถึงวันที่แบบ YYYY-MM-DD
- ดูภาพย้อนหลัง, แชร์รูปโดยตรงผ่าน Android Share Sheet, ย้ายภาพเข้าสู่ถังขยะ, กู้คืน, ยืนยันลบถาวร
- ลบถังขยะอัตโนมัติเมื่อถูกลบมาแล้วเกิน 30 วัน (ไม่ได้ลบหลักฐานที่ยังใช้งาน)
- ส่งออก ZIP พร้อมภาพ, วิดีโอที่มี, manifest.csv และ SHA256SUMS.txt ผ่าน Android Share Sheet
- โหมดวิดีโอทดลอง: เปิดผ่าน Settings และกดเริ่มบันทึกวิดีโอสำหรับ **ทั้งถุง** เชื่อมเหตุการณ์ Tracking ด้วย offset เวลาใน manifest.csv (ไม่ใช่คลิปแยกรายเลข Tracking)
- ถ้ามือถือไม่รองรับ Preview+Analysis+Video พร้อมกัน ระบบพยายามกลับไปใช้ Preview+Analysis เพื่อถ่ายภาพตามปกติ
- เลือกวันเก็บวิดีโอ 30/90/180 วันได้ (ปิดไว้เป็นค่าเริ่มต้น); การลบวิดีโอเก่าไม่ลบภาพ JPEG
- ข้อจำกัดพื้นที่: เตือนและหยุดบันทึกเมื่อพื้นที่ว่างน้อยกว่า 100 MB

## ยังไม่ได้ทำในรุ่นนี้ (อย่าเข้าใจว่าเสร็จแล้ว)

- คลิปแยกสำหรับ Tracking ทุกเลข และการยิงบาร์โค้ดเดิมเพื่อหยุดคลิป
- ฝัง Tracking ลงในไฟล์วิดีโอโดยตรง (ขณะนี้มี Tracking ในรูป และมีจุดเวลาในฐานข้อมูล)
- อ่านบาร์โค้ดจากเว็บแคมภายนอกหรือเครื่องยิง USB
- ลบคลิปไปอยู่ในถังขยะแล้วกู้คืนคลิป (ปุ่มลบวิดีโอเป็นการลบถาวร ต้องยืนยัน)
- ดึงรายการออเดอร์จาก Shopee/Lazada เพื่อระบุเลขที่ยังไม่สแกน
- ระบบหลายเครื่อง/Cloud Sync; รุ่นนี้ออฟไลน์เครื่องเดียว

## ขั้นตอนอัปเดตโปรเจกต์ใน GitHub

โปรเจกต์เดิม: https://github.com/paitoonsamba-hub/parcelguard-offline

1. สำรองรูปภาพและข้อมูลสำคัญจากแอปเดิมก่อนเสมอ เพราะ APK ที่ Build ใหม่บน GitHub อาจถูกเซ็นด้วย Debug key คนละตัว จนอัปเดตทับแอปเดิมไม่ได้ ต้องถอนการติดตั้งซึ่งทำให้ข้อมูลในเครื่องสูญหายได้
2. แตกไฟล์ ZIP ที่ให้มา บน Windows เปิดโฟลเดอร์ `ParcelGuard-Offline-Android`
3. ในหน้า Repo > Code > Add file > Upload files ลาก **โฟลเดอร์ `app` ทั้งโฟลเดอร์** ไปวาง โดยเก็บโครงสร้าง `app/src/main/...` อย่าลาก ZIP ทั้งก้อน
4. เมื่อ GitHub แสดงไฟล์ที่อัปโหลดใน path `app/...` และไม่มีโฟลเดอร์ซ้ำซ้อน ให้กด Commit changes
5. Workflow ที่คุณ Build #3 ผ่านแล้วสามารถใช้ต่อได้: Actions > Build ParcelGuard APK > Run workflow
6. ดาวน์โหลด Artifact, แตกไฟล์ได้ `app-debug.apk` แล้วทดลองติดตั้งบน Vivo V29

**ห้ามนำโฟลเดอร์ `ParcelGuard-Offline-Android` ทั้งโฟลเดอร์ไปวางซ้อนใน Repo** ไม่อย่างนั้น Gradle จะหาโมดูล app ไม่เจอ

## ทดสอบก่อนใช้งานจริง

1. เปิดแอป อนุญาตสิทธิ์กล้อง วางมือถือบนขาตั้งให้ QR/Barcode อยู่กลางกรอบ
2. สแกนเลขทดสอบ 3–5 หมายเลข ตรวจสอบว่าถ่ายภาพพร้อมข้อความ overlay ได้
3. ถือใบปะหน้าเดิมค้างไว้ 5 วินาที ต้องไม่เพิ่มรายการซ้ำ
4. ยกออกให้ไม่มีบาร์โค้ดอย่างน้อย 1 วินาที แล้วนำใบเดิมกลับมา ต้องแจ้งว่า Tracking ซ้ำ
5. ทดลองภาพค้นย้อนหลัง, ลบ→ถังขยะ→กู้คืน, ส่ง ZIP, เปิดรูปบนคอมพิวเตอร์
6. ตั้งเป้าหมาย 5 ชิ้นแต่สแกนแค่ 4 ชิ้นแล้วกดปิดถุง ต้องมีคำเตือนจำนวนไม่ตรง
7. ถ้าทดลองวิดีโอ ให้เข้า Settings เปิดโหมดวิดีโอ, กลับหน้าสแกน, เปิดถุง และกดบันทึกวิดีโอถุงนี้; ทดสอบการสแกนระหว่างบันทึก และตรวจว่าคลิปเล่นได้
8. ทดสอบบน Samsung ก่อนใช้งานจริง เพราะมือถือรุ่นประหยัดอาจไม่รองรับ 3 use cases พร้อมกัน

## ความเป็นส่วนตัว / สำรองข้อมูล

Repository GitHub **ไม่ควรมีรูปใบปะหน้าจริงของลูกค้า** ภาพและฐานข้อมูลอยู่ในพื้นที่ส่วนตัวของแอป Android โปรดสำรอง ZIP ลงคอมพิวเตอร์เป็นประจำ และตรวจข้อกำหนดเรื่องข้อมูลส่วนบุคคลก่อนแชร์ให้บุคคลอื่น

**หมายเหตุเรื่อง Debug APK:** การ Build คนละครั้งบน GitHub Runner อาจได้ลายเซ็น debug ต่างกัน ต้องใช้คีย์เซ็นเดียวกันเพื่ออัปเดตแอปโดยไม่ถอนติดตั้ง ในรุ่นทดสอบ ให้ Export ZIP ก่อนลองติดตั้ง APK เวอร์ชันใหม่
