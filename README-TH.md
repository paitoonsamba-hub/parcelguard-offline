# ParcelGuard Offline Android — รุ่นทดสอบ 0.1

**สถานะ:** ซอร์สโค้ดสำหรับทดลอง ยังไม่ได้ Build หรือทดสอบกับ Vivo V29 / Samsung จริง อย่าใช้เป็นหลักฐานส่งมอบพัสดุเพียงระบบเดียว

## ฟังก์ชันที่มี
- กล้องหลัง CameraX + ML Kit แบบ bundled (ไม่ต้องใช้อินเทอร์เน็ต)
- อ่าน Barcode และบันทึกภาพจากเฟรมที่สแกนเจอ
- ตรวจ Tracking ซ้ำทั้งฐานข้อมูล SQLite
- เปิดถุง/ปิดถุง นับจำนวน ค้นรูปย้อนหลัง
- ส่งออก CSV เฉพาะรายการ (ยังไม่ส่งออกรูปภาพ)

## สร้าง APK ผ่าน GitHub Actions
1. สมัคร/เข้าสู่ระบบ https://github.com
2. สร้าง **Private repository** ชื่อ `parcelguard-offline`
3. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดจาก ZIP ไปยังราก repository (รวม `.github/workflows/build-apk.yml`)
4. เข้าแท็บ **Actions** > **Build Android APK** > **Run workflow**
5. รอ workflow สำเร็จ แล้วดาวน์โหลด artifact `ParcelGuard-Offline-debug-apk`
6. แตก ZIP ที่ดาวน์โหลดจาก GitHub จะได้ `app-debug.apk`
7. ส่ง APK ไปยัง Vivo V29 แล้วเปิดไฟล์เพื่ออนุญาตติดตั้งจากแหล่งนี้ (เฉพาะที่เชื่อถือ)

**สำคัญ:** ถ้า GitHub ไม่แสดง workflow ให้ตรวจว่า `.github/workflows/build-apk.yml` ถูกอัปโหลดถูกที่ และ branch เป็น `main`.

## ข้อจำกัดที่ต้องแก้ก่อนใช้งานจริง
- รุ่นนี้เป็น MVP ทดลอง; ไม่ได้ทดสอบ Build บน Android SDK ในสภาพแวดล้อมนี้
- ต้องทดสอบการอ่านบาร์โค้ด/ถ่ายภาพบน Vivo V29 และ Samsung จริง
- ยังไม่มีการบังคับให้ยกพัสดุออกจากเฟรมก่อนอ่านเลขใหม่
- การเปิดถุงใหม่ยังไม่บังคับเลือกขนส่งตามถุงแบบถาวร
- CSV ยังไม่รวมภาพและยังไม่มีสำรอง/กู้คืนเต็มรูปแบบ
- ข้อมูลแอปอาจหายเมื่อลบแอปหรือรีเซ็ตเครื่อง
- แอปไม่ได้ซิงก์คลาวด์ และไม่ควรนำข้อมูลส่วนตัวลูกค้าไปใส่ repo
