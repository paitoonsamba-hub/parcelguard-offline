# ParcelGuard Offline V0.3.0 — Orange Industrial UI

## สถานะ
ซอร์ส Android สำหรับ Build APK ผ่าน GitHub Actions; **ยังไม่ได้ Build V0.3.0 และยังไม่ได้ทดสอบบน Vivo V29 หรือ Samsung** (รุ่นก่อนหน้า V0.2.2 เคย Build ผ่าน)

## สิ่งที่เปลี่ยน
- ธีมสีดำ–ส้มตามแบบที่เลือก: การ์ดเข้ม, ปุ่มหลักสีส้ม, ข้อความชัดเจน, กรอบสแกนกล้อง และเมนูด้านล่าง
- ไอคอนแอปใหม่: กล่องติดบาร์โค้ดในกรอบสแกนสีส้ม ทั้งไอคอนปกติและไอคอนวงกลม
- หน้าแพ็ค: ถุงปัจจุบัน, ขนส่ง, จำนวนสแกน, แถบความคืบหน้า, เป้าหมาย, เปิด/ปิดถุง, Preview กล้อง, ไฟฉาย, ถ่ายภาพด้วยมือ, วิดีโอทดลอง
- หน้า 'รายงาน' แสดงจำนวนถุงและพัสดุ พร้อมปุ่มส่งออก ZIP
- คงระบบเดิมจาก 0.2.2: ML Kit Barcode สแกนอัตโนมัติ, รูปพร้อม Tracking + เวลา, SQLite, แจ้งเสียง 'บันทึกแล้ว', ค้นย้อนหลัง, ถังขยะ, ZIP, โหมดวิดีโอถุง และหน้าตั้งค่า
- เพิ่มปุ่ม 'ถ่ายภาพ' กรอกเลข Tracking และใช้ภาพจากกล้องเมื่อบาร์โค้ดสแกนยาก (ต้องตรวจเลขด้วยตนเอง)

## วิธีอัปเดต GitHub แบบเร็ว
1. **สำรอง ZIP หลักฐาน** จากแอปรุ่นเดิมก่อน โดยเฉพาะหากมีรูป/วิดีโอสำคัญ
2. แตกไฟล์ `ParcelGuard-V03-Orange-UI-GitHub-Update.zip`
3. เข้า GitHub Repo `paitoonsamba-hub/parcelguard-offline` > Code > Add file > Upload files
4. ลาก **โฟลเดอร์ `app` จากใน ZIP** ลงในหน้าต่างอัปโหลด (ต้องเห็น path `app/src/main/...` และ `app/build.gradle`)
5. กด Commit changes
6. ไป Actions > Build ParcelGuard APK > Run workflow (ถ้า workflow ทำงานอัตโนมัติจาก push แล้ว ไม่ต้องกดซ้ำ)
7. เมื่อ Success เข้า Build run > Artifacts > ดาวน์โหลด `ParcelGuard-Offline-APK`, แตก ZIP แล้วจะได้ `app-debug.apk`
8. ส่ง APK ไป Vivo V29 แล้วติดตั้ง / ทดสอบ

### ถ้าติดตั้งทับไม่ได้
GitHub Actions แบบ debug อาจสร้างด้วยลายเซ็นใหม่ทุกครั้ง จึงอาจติดตั้งทับแอปเก่าไม่ได้ ควรสำรองหลักฐานก่อนถอนการติดตั้ง เพราะถอนแอปจะลบข้อมูลที่เก็บในพื้นที่ส่วนตัวของแอป หลังทดลองควรสร้าง signing key คงที่สำหรับอัปเดตครั้งถัดไป

### ทดสอบก่อนนำไปใช้งานจริง
- เปิดกล้องหลังได้และสแกนอัตโนมัติ
- พอถ่ายภาพและบันทึก SQLite สำเร็จได้ยินเสียงแจ้งเตือน
- ป้องกันเลข Tracking ซ้ำ
- เปิด/ปิดถุง นับและตั้งเป้าหมายถูกต้อง
- ปุ่มถ่ายภาพด้วยมือสร้างภาพพร้อม Tracking และเวลา
- ประวัติ ค้นหา และส่งออก ZIP
- วิดีโอทดลอง: เฉพาะเครื่องที่รองรับ CameraX Preview+Scan+Video พร้อมกัน

### ข้อจำกัด
- รูปแบบหน้าจอเป็น Android native programmatic layout ที่ยึดแรงบันดาลใจจากภาพต้นแบบ ไม่ใช่ภาพ mockup ที่แปะเป็นหน้าจอ และอาจไม่เหมือนภาพ 100%
- โหมดวิดีโอเดิมมีข้อจำกัดหนึ่งคลิปต่อถุง; ใช้เมนูจัดการคลิปก่อนถ่ายใหม่
- ข้อมูลจัดเก็บแบบ Offline ในมือถือเท่านั้น; ไม่มีซิงก์คลาวด์
- ยังไม่มีการ Build หรือทดสอบ V0.3.0 บนเครื่องจริง
